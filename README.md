# 星账 · ledger-final

看清实际账户中的钱、资金归属与性质，便捷记账，以微信/支付宝官方账单补全与核对。双人使用保持个人账本边界，对象只读；手机与桌面共享业务规则。

## 当前状态

核心设计已收敛，现有参考脚本用真实官方文件和虚构账户完成流程验证；**尚无已部署应用、生产API或数据库闭环**。不把文档和内存参考检查当成产品功能验收。

## 简单链路

M1授权→M4读取/标准化/来源与账户判断→可处理行调用M3统一账务→M2账户与份额结果→M5只读统计。来源不等于交易，读取不等于入账；退款独立、无原消费关联，日期和抵减可编辑。

M1–M5始终是业务模块，不是里程碑编号。每次实现任务限定主责、依赖、允许修改范围、验收；不重复扫描/重构全部项目，不创建第二套余额或保存逻辑。Git主干main，提交使用Conventional Commits。

当前验证：107项参考检查通过；338条真实来源在虚构账户参考流程中162创建、125不支持、1不生效、50待处理。细节和限制以实施计划为准，不声称实际识别入账率。原始账单和个人逐行报告不提交公开仓库。

API行为格式先在创建交易与编辑退款试点：异常、副作用、失败状态和验收动作已写清。幂等、原生事务方案及版本比较见实施计划D1–D3，待用户选择，不是已开启能力。选择后只把两个试点转为OpenAPI，不一次生成全项目规格。
