## 协作方式

- 主干 `main` 始终可发布；改动走 `feat/*`、`fix/*`、`chore/*` 分支 + PR。
- 提交信息遵循 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/)。
- 需求与缺陷统一用 Issue 跟踪，PR 必须关联 Issue。
